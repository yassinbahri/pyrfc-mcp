# Changelog

All notable changes will be documented here. This project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and intends to use
[Semantic Versioning](https://semver.org/) once stable releases begin.

## [Unreleased]

### Added

- Connection-affine SAP transactions with opaque IDs, expiry, and shutdown rollback.
- Bounded connection-pool acquisition timeouts.
- MCP read/write risk annotations.
- Locked dependencies, CI, security scanning, contribution guidance, and templates.

### Changed

- Read access is deny-by-default and must be explicitly allowlisted.
- PyRFC is an optional, exactly pinned legacy dependency.
- Local MCP configuration is now supplied as a portable example.

### Removed

- Generated bytecode, local session files, and runtime logs from the distributable tree.
